## Deployment

To set up Devine Music, follow these steps:  

1. Clone the Repository  
   ```bash
   git clone https://github.com/devineparadox/Devine-Music && cd Devine-Music```

2. Run the Installer

```bash install.sh```


3. Configure Environment Variables
Enter the required API keys and database details during installation or manually edit .env.


4. Start the Bot

```bash start```
